# CQA - Critical Quality Assurance Prototype

This is a quality control application for factory floor inspections, featuring AI-powered failure prediction and comprehensive reporting.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Deployment

### GitHub Pages Deployment

1. Build the app:
   `npm run build`
2. Deploy to GitHub Pages:
   `npm run deploy`

Or use the automated GitHub Actions workflow by pushing to the main branch.
